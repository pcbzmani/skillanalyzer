GitHub Actions workflow

Add to .github/workflows/build-analyze.yml. Runs on every PR and push to main — posts a bundle size diff comment automatically. 

name: Build Analyzer
on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  analyze:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build with stats
        run: npm run build -- --stats
        env:
          NODE_ENV: production
          GENERATE_SOURCEMAP: 'false'

      - name: Analyze bundle (PR comment)
        uses: preactjs/compressed-size-action@v2
        with:
          repo-token: ${{ secrets.GITHUB_TOKEN }}
          pattern: './dist/**/*.{js,css}'
          compression: gzip
          minimum-change-threshold: 100

      - name: Upload build artifact
        uses: actions/upload-artifact@v4
        with:
          name: build-stats-${{ github.sha }}
          path: |
            dist/stats.json
            dist/
          retention-days: 30
Bundle budget enforcement step

Add this step to fail the CI build if your bundle exceeds a defined size budget.

      - name: Enforce bundle budget
        run: |
          BUDGET_KB=900
          SIZE_KB=$(du -sk dist/ | cut -f1)
          echo "Bundle size: ${SIZE_KB}KB (budget: ${BUDGET_KB}KB)"
          if [ "$SIZE_KB" -gt "$BUDGET_KB" ]; then
            echo "::error::Bundle (${SIZE_KB}KB) exceeds ${BUDGET_KB}KB budget!"
            exit 1
          fi
          echo "::notice::Bundle OK — ${SIZE_KB}KB of ${BUDGET_KB}KB used"

netlify.toml — root configuration

Place at the root of your repo. Netlify picks it up automatically on every deploy.

[build]
  command   = "npm run build"
  publish   = "dist"
  functions = "netlify/functions"

[build.environment]
  NODE_VERSION        = "20"
  NPM_FLAGS           = "--prefer-offline"
  GENERATE_SOURCEMAP  = "false"
  CI                  = "true"

# Long-lived cache for hashed assets
[[headers]]
  for = "/assets/*"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"

# No-cache for HTML entry points
[[headers]]
  for = "/*.html"
  [headers.values]
    Cache-Control     = "no-cache, no-store, must-revalidate"
    X-Frame-Options   = "DENY"
    X-XSS-Protection  = "1; mode=block"
    Referrer-Policy   = "strict-origin-when-cross-origin"

# Deploy preview — lighter build
[context.deploy-preview]
  command = "npm run build:preview"

[context.branch-deploy]
  command = "npm run build"

# Lighthouse plugin
[[plugins]]
  package = "@netlify/plugin-lighthouse"
  [plugins.inputs]
    output_path = "reports/lighthouse.html"
    audits      = ["performance", "accessibility", "best-practices"]
Netlify build plugin — bundle budget

Create netlify-plugin-bundle-budget/index.js and register it in netlify.toml.

// netlify-plugin-bundle-budget/index.js
const { execSync } = require('child_process')
const path = require('path')
const fs   = require('fs')

const BUDGET_KB = 900  // change this

module.exports = {
  onPostBuild: async ({ utils, constants }) => {
    const publishDir = constants.PUBLISH_DIR
    const sizeKB = parseInt(
      execSync(`du -sk "${publishDir}"`).toString().split('\t')[0]
    )

    const assets = fs.readdirSync(path.join(publishDir, 'assets'))
    const jsKB = assets
      .filter(f => f.endsWith('.js'))
      .reduce((sum, f) => {
        return sum + fs.statSync(path.join(publishDir, 'assets', f)).size
      }, 0) / 1024

    console.log(`  Total bundle:  ${sizeKB} KB`)
    console.log(`  JS only:       ${jsKB.toFixed(1)} KB`)
    console.log(`  Budget:        ${BUDGET_KB} KB`)

    if (sizeKB > BUDGET_KB) {
      utils.build.failBuild(
        `Bundle (${sizeKB} KB) exceeds the ${BUDGET_KB} KB budget. ` +
        `Reduce by ${sizeKB - BUDGET_KB} KB to pass.`
      )
    }
  }
}

Register the plugin in netlify.toml:

[[plugins]]
  package = "./netlify-plugin-bundle-budget"
